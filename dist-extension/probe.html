Persistence

Stamp, then close the tab and rejoin the room. Reopen this panel: a surviving stamp means the store persists, and an unchanged player id means it is stable across rejoins.

Capacity

Doubling search then bisection with incompressible filler, so these measure a byte budget rather than a compression ratio. Item and scene need a token selected / a scene open.

Local-item attachment

Select a token. Attaches a non-synced marker, moves the token 250 units, and checks whether the marker followed. Decides whether status badges can be local — which would avoid leader election and scene clutter entirely. Puts the token back afterwards.

Item metadata write (run this as a PLAYER too)

Select a character token first. Tests whether a non-GM can write item metadata, which decides whether players can own their own sheets.
